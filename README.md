# Tilez for Windows and Mac

Tilez shows your home on one screen: lights, heating, energy, cameras and more, from the devices and services you already have.

**Download** the latest version from [Releases](https://github.com/activa/tilez/releases/latest).

- **Windows** (10 and 11, 64-bit): run `Tilez-Setup-<version>.exe`. It installs for you alone, without asking for an administrator, and adds Tilez to the Start menu. The installer is not signed yet, so Windows may say "Windows protected your PC": choose **More info**, then **Run anyway**. Running a newer installer updates Tilez in place; your dashboards stay.
- **Mac:** coming soon.

Tilez is also on Android and iOS, and a Tilez Hub serves it to any browser at home ([activa/tilez-hub](https://github.com/activa/tilez-hub)).

This repository holds only the downloads.
